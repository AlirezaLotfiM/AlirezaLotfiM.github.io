Enterprise Queue Platform — پلتفرم جامع نوبت‌دهی نداپرداز

پلتفرم بومی و جامع مدیریت نوبت و روان‌سازی صف نداپرداز انفورماتیک؛ شامل نرم‌افزارهای دسکتاپ ویندوزی کیوسک‌های لمسی اخذ نوبت، کلاینت‌های تلر (Teller Unit)، موتور نمایشگرهای تلویزیونی سالن (TV Display Engine)، سیستم نوبت‌دهی جدید با پشتیبانی از استندهای دکمه‌ای فیزیکی و اپلیکیشن‌های موبایل Flutter. پیاده‌سازی و استقرار در شعب بانک‌های مطرح کشور (بانک ملت، بانک آینده، بانک شهر).

نقش
توسعه‌دهنده ارشد و پشتیبان سیستم‌ها
فناوری‌ها
C# / WPF / Flutter / Hardware
معماری
WPF Kiosks + TV Display Engine + Physical Hardware Control Units + Flutter Mobile App + SQL Server
اثر
دیجیتالی‌سازی کامل صف‌ها، کاهش زمان انتظار و مدیریت روزانه صدها هزار مراجعه‌کننده

جزئیات فنی

  • توسعه نرم‌افزار دسکتاپ کیوسک‌های لمسی صدور نوبت جهت احراز هویت، انتخاب سرویس و چاپ فیش نوبت
  • توسعه کلاینت‌های دسکتاپ باجی (Teller Units) جهت فراخوانی نوبت، انتقال، غیبت و مدیریت صف
  • طراحی موتور نمایشگرهای تلویزیونی (TV Display Engine) جهت پخش زنده شماره نوبت‌ها، اعلان‌های صوتی و ویدیوهای اطلاع‌رسانی
  • توسعه سیستم نوبت‌دهی نرم‌افزاری نسل جدید با پشتیبانی مستقیم از استندهای دکمه‌ای فیزیکی و کنترل یونیت‌های سخت‌افزاری
  • طراحی و پیاده‌سازی اپلیکیشن‌های کراس‌پلتفرم موبایل با فلاتر (Flutter) جهت نوبت‌دهی غیرحضوری و پیگیری وضعیت
  • یکپارچه‌سازی و سفارشی‌سازی بر اساس الزامات اختصاصی بانک‌های کشور (بانک ملت، بانک آینده، بانک شهر)
  • ارتباط بلادرنگ کلاینت‌ها با سرور نوبت‌دهی مرکزی و پایگاه داده SQL Server
  • ماژول گزارش‌گیری و آماری جهت تحلیل زمان انتظار مشتریان، کارایی باجی‌ها و ساعات اوج مراجعه
  • سیستم اعلام صوتی باگس‌گیری‌شده و هوشمند با پشتیبانی از فایل‌های صوتی دینامیک
  • پشتیبانی فنی مداوم، دیباگ عملیاتی و به‌روزرسانی زیرسیستم‌های فعال در شعب
