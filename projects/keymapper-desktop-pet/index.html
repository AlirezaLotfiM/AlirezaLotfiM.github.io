فعال

KeyMapper Desktop Pet

برنامه دسکتاپی ویندوزی با همراه پیکسل‌آرت زنده؛ ترکیبی از دستیار هوش مصنوعی محلی، پخشگر موسیقی هوشمند، OCR چندزبانه، ترجمه آنلاین و آفلاین، میانبر صفحه‌کلید و ابزارهای کاربردی روزمره. ساخته‌شده به‌صورت مشترک، به‌طور مداوم در حال توسعه.

نقش
توسعه دهنده مشترک
فناوری‌ها
C# / WPF / LLamaSharp / Tesseract
معماری
WPF App + Local LLM + Tesseract OCR + LibreTranslate + Global Hooks
اثر
ابزار دسکتاپ رایگان با AI محلی و حریم خصوصی کامل

جزئیات فنی

  • ۶ همراه پیکسل‌آرت با شخصیت متمایز: Pip، Professor Owlet، Dude، Frieren، Yuji Itadori، Luffy
  • هوش مصنوعی محلی با LLamaSharp + مدل‌های Qwen3/Qwen2.5 GGUF (Lite تا Max، ۶۳۹MB تا ۹GB)
  • پخشگر موسیقی با تحلیل ریتم، شناسایی mood، انیمیشن beat-reactive و کتابخانه محلی
  • OCR سه‌زبانه (فارسی، انگلیسی، آلمانی) با Tesseract و چند پاس پیش‌پردازش
  • ترجمه زنده با LibreTranslate — نصب اختیاری محلی بدون نیاز به Docker یا Python سیستمی
  • تبدیل layout صفحه‌کلید غلط (فارسی/انگلیسی/آلمانی) به متن صحیح
  • Text Expansion با متغیرهای {date}، {time}، {clip}، {sel}، {cursor}
  • Command Palette برای جستجو و اجرای میانبرها و اکشن‌ها
  • اجرای برنامه و بازی‌های Steam، با راهنمایی برای موارد ناموجود
  • ۷ تم رنگی (Warm Cream، Midnight Pixel، Cyber Groove و ...) با اعمال فوری
  • حافظه مکالمه محلی تا ۱۲ گفتگو برای هر شخصیت
  • PixelYar Cloud: پیش‌نمایش سرویس hosted روی Cloudflare Workers
  • یادآوری (Reminder)، یادداشت چسبنده (Sticky Notes)، اسکرین‌شات ناحیه‌ای
  • Global keyboard/mouse hook برای شناسایی میانبرها در کل سیستم
